一、阶段起点与目标
================================================================================

本阶段起始于《历史迭代阶段/20261127-1327_UI代码无损清理CSS分文件与组件拆分及样张未接线功能删除与手机原生App手感五项落地.txt》之后。当时 main 顶点为 f6c3cc1。

起点时的 UI 状态：
- 设计系统：鼠尾草绿 + 墨色。
- 页面形态：每页是一页长卷，内容在同页展开。
- 底栏标签：四字全称（首頁 / 血糖紀錄 / 問 AI / 問題紀錄 / 個人檔案）。
- 下拉选择：原生 select。
- 录入表单：直接摆在页面上。
- 删除：没有二次确认。
- 切页时页面卸载，问 AI 回复与 AI 總結会因此丢失。

目标（项目主人 2026-11-27 对齐）：
- 模仿侧（本仓库，糖友导航）看起来要出自被仿侧 DiaGuide HK 的同一位设计师之手，而且是他之后深思熟虑的升级版。
- 非 UI 的核心业务零变化。
- 像 app，不像网页。
- UI 层可以大胆重构，UI 之外只做最小必要的改动。
- 意图对齐后，按有规划的多阶段迭代自主推进。

被仿侧的设计语言、模仿侧的业务边界（"不能动清单"与灰色地带 G01–G30），都先在仓库外整理成文档，再动手。

整轮不变的运行边界：
- 端口 9002 上带真实密钥的 dev 服务直接从仓库工作区热加载，所以全程不碰它，也不切仓库工作区的分支。

- 验证网与截图、行为检查脚本都在浏览器内拦截 /api/gemini/*。全程零真实 AI 请求，没有任何真实数据离开浏览器。
