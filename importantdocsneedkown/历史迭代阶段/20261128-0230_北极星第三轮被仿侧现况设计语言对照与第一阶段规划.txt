================================================================================
一、被仿侧此刻的设计语言（读到的关系，不是一张清单）
================================================================================

1. 底与色
- 纸底是很浅的暖薄荷灰（视觉上接近 #F5F7F4 / theme-color #f5f6f6；令牌里仍有 #f7f9f5、#f6f7f5）。不是冷蓝网页底。body 计算样式里残留的蓝白渐变被页面自己的纸色盖住，用户看见的是纸，不是渐变。
- 领域粉彩仍然是他的声音：天空蓝（AI、血糖）、丁香紫（覆诊、问题）、鼠尾草绿（药物、录音、空状态按钮）、浅黄油（饮食）。粉彩是大面积的卡，白是卡上的按钮和输入。
- 炭黑 #2F3033 只给「按这里 / 你在这里」：开始使用、下一步、底栏选中格、保存。次动作是白底浅描边圆角胶囊。
- 墨色是暖炭灰（标题约 #373531，说明更淡）。品牌眉标「DiaGuide HK」用深苔绿，声音很轻。

2. 字阶与字重（标准字下的现场采样）
- 欢迎页主标题约 42px / 字重 650，行距宽松；说明 20px 上下；主按钮高 64px。
- 首页问候是一行中等标题，不占一整头；卡片主标题（下次覆诊、未设定）比说明大一档，数字/空值（—、未設定）再大一档。
- 底栏两字标签约 16px / 600。放大字（Aa 放大）在首页上是温和放大，不是把整页撑破。
- 字体栈：PingFang TC / Noto Sans TC，字距为 0，标题 keep-all。模仿侧已是 Noto Sans HK 与相近字阶；关系对了，不需要另起一套。

3. 形、间距、分量
- 卡片圆角大约 26px，按钮/输入约 16–999 胶囊，底栏是悬浮白胶囊。卡片本身几乎没有描边和硬影，靠底色分层；只有悬浮物（底栏、语音钮、弹层）带很淡的暖影。
- 一屏里的重点很少：欢迎页只有一句欢迎和一颗开始；首页是「问候 + AI 主卡 + 覆诊卡 + 两枚并排摘要」。不会在一屏里同时摆开统计、图表、清单和说明。
- 触控区普遍 48–56px 高，主按钮更接近 56–64。

4. 动效与壳
- 令牌：instant 120ms、standard 200ms、enter 240ms，ease cubic-bezier(.2,.8,.2,1)。与模仿侧已有时钟一致。
- 导航骨架不动：悬浮胶囊底栏，选中格是炭黑圆角块，图标 24px、线条约 1.8。子页从右侧滑入，圆返回钮加大标题。语音钮浅草绿圆浮钮，不抢主按钮的炭黑。
- 桌面宽屏会给 #device-shell 加手机外框；真机 390 宽时没有外框。对照一律按无外框的手机视口。

5. 图像
- 欢迎页是水彩叶片，落在纸色里，不喧宾夺主。
- 首页 AI 卡有一只浅立体机器人，覆诊卡有日历插画；药物页有胶囊插画。空状态用简单线性图标（水滴、清单）。
- 这些图是他的笔迹。模仿侧这一阶段先把位置、比例和底色留对，插画用克制的装饰位，稍后用生图补一套真正像他的静态资源。宁可空着，也不放一张不像他的图。

6. 流程的步调
- 先是安静的欢迎（「歡迎使用 / 糖友導航 / 記錄日常健康，輕鬆準備覆診。」），准备好再出现炭黑「開始使用」。
- 首次设定是盖在首页之上的一张张卡片：顶栏「初次見面，認識一下您」+ 1/5 进度，一次只问一屏（基本资料等），主按钮「下一步」，次按钮「稍後填寫」，语音钮在次按钮旁。
- 记血糖是一张子页：日期 / 时间 / 时段挤在一条白卡里，中间是半圆量尺和 mmol/L，可选的饮食、运动、症状是三枚粉彩方块，保存键在下面。
- 问 AI 先给「今天想問甚麼？」和四枚主题粉彩卡，输入是底部一颗白胶囊（+、占位、麦克风），不是一块占满屏的对话空壳。
- 问题页以丁香紫为主：下次覆诊一条、新增问题 / AI 幫我整理，然后是「本次覆診要問 / 尚未加入」两个空状态卡。

================================================================================
二、并排放着，此刻最不像、最不顺手的几处
================================================================================

（前两轮已经把气质的「底」铺上了。下面是这一轮对照里仍然会让人觉得「不是同一版产品」的地方。）

1. 首页结构（最高杠杆）
- 被仿侧：一行问候（头像、品牌、早安、Aa）→ 天空蓝「問問 AI」主卡（開始提問 → + 插画）→ 丁香紫「覆診安排 / 下次覆診」大卡（两个白按钮）→ 并排「最新血糖」「今日服藥」摘要砖。
- 模仿侧：问候是单独大标题；問問 AI 已是蓝卡但还是「图标-文案-箭头」横条，没有「開始提問」这句行动；覆诊卡标题是「下次問診清單」，日期和空清单、说明挤在一张卡里；血糖是「最近血糖」统计砖，主按钮是「查看紀錄」；完善档案是另有一张绿卡。并排的摘要感没有出现。
- 具体时刻：打开 app 的第一眼，想先看见「我下次什么时候去、最近一次血糖、要不要问 AI」。现在要往下找，重点也平铺了。

2. 记血糖的入口和那一张表
- 被仿侧纪录页：顶上一行分段（血糖與糖化 / 症狀紀錄 / 數據日誌），空状态是水滴和一句「還沒有血糖紀錄」，下面两颗浅绿满宽「+ 記錄血糖 / + 記錄糖化」。进入记录是半圆量尺那一张。
- 模仿侧：三个并列标签（血糖紀錄 / 症狀紀錄 / 糖化），入口是带草稿时间的记录卡，下面还有统计和图表的空位，表格本身是传统的「测量时间、测量时段、数值输入、完成儲存」。
- 具体时刻：空着手打开纪录，应先感到「这里很安静，按一下就可以记」；记的时候眼睛应落在那个大数字上，而不是先面对一排字段。

3. 欢迎与首次设定的步调
- 被仿侧先欢迎、再一张一张问。模仿侧一进来就是「歡迎來到『糖友導航』」加上第 1 步整张基本资料表（称呼、年龄、性别、身高体重），「下一步」在未填时是灰的，说明「請先填寫年齡及選擇性別」。
- 字段、取值、何时算填完，属于约定，这一轮不动。变的是「一次让眼睛停在多少问题上」，以及纸面上的进度与主次按钮。这是设计师的事，但要非常小心保存时机。规划在首页与纪录站稳后再做，以免一次改太多流程。

4. 问 AI、问题、我的
- 问 AI 的主题卡矩阵、底部胶囊输入，问题页的丁香空状态，我的页「已完成 n/5」身份卡，都还和被仿侧差一截。它们是下一阶段的主战场。
- 被仿侧有「我的藥物 / 今日服藥 / 數據日誌 / 帐户登入」。模仿侧在阶段十一卸下了未挂载的 MedicationReminders，但 profile 里仍有 medications / medicationDetails，也仍有 dia_reminders_v2。本阶段不重做药物模块，也不在首页造一枚会改提醒规则的「今日服藥」。是否用现有数据做一枚只读摘要，留给主人决定。

5. 已经比较像、这一轮不去动的
- 令牌家族（暖纸、粉彩、炭黑、深苔绿焦点）和动效时钟。
- 悬浮胶囊两字底栏、子页、底部抽屉、单一滚动根、键盘避让、再点 Tab 回顶、问 AI 锚定。
- 问候语由 domain/greeting 算出，免责声明原文，data-verify 钩子。这些保持原样。

================================================================================
三、第一阶段要做的（只做能说出「哪一刻更好」的）
================================================================================

目标：打开模仿侧的人，在首页和纪录这两段路上，会开始觉得「这就是被仿侧长大以后的样子」。不引入新的存储键，不改计算、提醒规则、/api/gemini/* 与锁定文案，不增删依赖，不改 Worker 名、路由或密钥。

1. 首页改成他会给出的那一块仪表
   - 顶行：头像（进「我的」）、DiaGuide HK 眉标、问候语原文、Aa 字号胶囊（data-verify=font-toggle 只保留一处）。
   - 「問問 AI」主卡补上「開始提問 →」，插画位先做克制的装饰，不放不像他的图。钩子 consult-open 不变。
   - 覆诊卡改成「覆診安排 / 下次覆診」的语气和两枚白按钮（设定日期、查看清单）。日期字段仍只有现有的 nextClinicDate；不新增时间或地点。已有的今日/还剩几天/已过期提示留下，这是向内的体贴。选好的问题仍可在卡下瞥见。
   - 并排摘要：左「最新血糖」（空为 — 与「尚未有血糖紀錄」，有值则显示数字；按钮进入纪录）。右不造药物。未完善档案时放「個人檔案 / 去完善」；已完善时放「問診清單」和已选题数。原先单独的「去完善」卡收进这枚砖，避免两个入口。
   - 今日是覆诊日的那条横幅留下（已经很好）。

2. 纪录页的空状态与记一笔的那张表
   - 顶部分段看起来像他的白胶囊 + 炭黑选中，标签收成更短的称呼（血糖 / 症狀 / 糖化）。钩子 records-tab-* 不变。不新增「數據日誌」。
   - 没有记录时，先看到安静的空状态和满宽的「+ 記錄血糖 / + 記錄糖化」，统计和空图表退到有数据再出现。
   - 记录子页：时间与时段收成一排，数值成为视觉中心（半圆量尺是装饰，输入框和校验、范围、保存逻辑不动），饮食 / 运动 / 症状仍是原来的可选明细，只是入口长得像三枚粉彩砖。葡萄糖保存文案、alert、data-verify=glucose-value / glucose-save 不变。

3. 外壳只做吸收，不做换骨
   - 首页不再单独占一行品牌眉标（眉标进问候行），避免双行头部。其他主页的字号胶囊维持。
   - 底栏不改信息架构，不改两字标签。若选中格分量还差一点，只做样式上的靠近。

4. 明确不做（本阶段）
   - 不重做药物模块，不改提醒。
   - 不把首次设定拆成五步、不改必填与保存时机（欢迎页与一张一张问，放到下一阶段）。
   - 不改问 AI 发给模型的锁定文案和快捷问题的业务含义；主题卡矩阵放到下一阶段。
   - 不改 dia_* 键与结构，不改 vite / server / package.json 脚本与依赖。
   - 生图插画可以后补。
