一、被仿侧图案手法调研
- 地址比对：https://diaguide-hk.thetax.workers.dev 为构建产物；https://tangyou-pro.alphathought.org 可用(200)，是同一源码的 Vite 开发服务器（src/assets/...）。两边图片逐个 md5 一致（ai-card-refined / appointment-card / robot / topic-glucose / topic-diet / topic-emergency / topic-medication），即两者同版；pro 那边会话直接跳过欢迎页进 1/5 设定，故以 workers.dev 为截图对象。
- 介质：全部为位图 webp（2–17 KB），没有 SVG 插画、没有 CSS 渐变球、没有 emoji。两种笔迹：
  1) 水彩：欢迎页 leaves-background（640×1391，近白薄荷底 #f6faf4 左右，仅右上一枝、左下一丛半透明叶片，无描边，亮度 176–255，中间约 70% 空白）；「我的」identity-background（薄荷水彩洗 + 右下两座圆丘 + 小芽）。
  2) 哑光黏土 3D：首页 AI 卡（淡天蓝平铺底 + 右侧浅色圆斑 + 白色机器人 + 三条绿色动势短线），覆诊卡（淡丁香底 + 圆斑 + 日历时钟 + 紫色动势短线），问 AI 引导 robot（同色页底 + 薄荷斑 + 机器人）。
  3) 主题卡底图：卡片同色系纯色 + 右下两层圆丘，对比度极低（亮度跨度 ~20），opacity .45、object-position right bottom。
- 排布：一张图只放一个物件、靠右或角落，占卡片约 1/3，其余是与卡底同色的留白；文字压在留白上，图在文字层下。线性图标保持 24px / 1.8 描边、无底圈。

二、模仿侧为何显得不自然（见 /workspace/northstar-shots/p3-welcome-before.png）
1. 介质不同：我们用 inline SVG 描边叶 + 4 层 radial-gradient，被仿侧是水彩位图；描边线条硬、细且一致，读起来像「图标」不像「插画」。
2. 晕染发脏：多层径向渐变在灰底 #f5f6f6 上形成大块灰绿色斑，像污渍而非纸面。
3. 叶形几何化、只露一角被裁切，缺少叶脉与半透明叠色，没有「生长」感。
4. 首页/问 AI 用「线性图标 + 半透明白方块」或「CSS 高光球」代替插画，和水彩叶不是一家人；光源、材质、配色各自为政。
5. 主题卡用白色径向光斑代替底图，像高光反射，不像风景。
